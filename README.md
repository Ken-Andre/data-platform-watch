## 🎬 Annexe — Showreel motion design

En complément de la veille : un showreel de motion design 100 % procédural (15 s, 1080p60 + cut 9:16),
généré image par image par un compositeur numpy/OpenCV maison — typographie cinétique à axes variables,
simulation de particules, bande-son synthétisée. L'aperçu ci-dessous se joue tout seul ;
un clic ouvre le reel complet **avec le son, lu dans le navigateur, sans téléchargement** :
